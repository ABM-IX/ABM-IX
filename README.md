### 🚀 Featured Work

Most of my code belongs to First Minds or to team projects, so the repositories are private. Each project below links to something you can open. I'm happy to walk anyone through the code.

| Project | What it does | Stack | See it |
| :--- | :--- | :--- | :--- |
| **Smart Transit** | Public transport platform for combis, buses and taxis. The driver app shares GPS every 4 seconds, and the back end tells each driver to slow down or speed up so combis stop bunching. It also gives arrival times, plans trips across taxis, combis and intercity buses, and has an operator console. | `Flutter`, `FastAPI`, `Socket.IO`, `Supabase PostGIS`, `React` | [Walkthrough video](https://www.youtube.com/watch?v=BS1-mfaJKo4) |
| **Leseding AI Engine** | Voice AI that answers customer calls in Setswana and English, on the web and by phone. Third place, Orange Summer Challenge 2026. I built the noise suppression and the website, and worked on the engine's architecture. | `Python`, `FastAPI`, `Whisper`, `Telnyx` | [lesedingaiengine.co.bw](https://lesedingaiengine.co.bw/) |
| **Study Hub** | Exam preparation from a learner's own notes and past papers: it shows which questions keep coming back, then builds drills, a predicted paper and marking against the scheme. | `React`, `TypeScript`, `Firebase`, `Claude API` | [Early version](https://abm-ix.github.io/study-site/) |
| **Mokgosi** | Personal safety and GBV response network. An alert reaches trusted contacts and a responder console together. | `Flutter`, `FastAPI`, `PostGIS`, `React` | [Live demo](https://mokgosi-dashboard.onrender.com/) |
| **BOCRA Connect** | Redesigned regulator website with an assistant that answers questions from BOCRA's own pages and documents. | `React`, `FastAPI`, `Embeddings`, `LLM` | [Live site](https://bocra-inky.vercel.app/) |
| **HouseConnect** | Android app for finding student accommodation in Gaborone, with live vacancy updates. | `Kotlin`, `Cloud Firestore`, `Firebase Auth` | [Repository](https://github.com/ABM-IX/HouseConnect) |
